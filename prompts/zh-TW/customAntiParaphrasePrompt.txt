═══ 反轉述模式（Anti-Paraphrase） ═══
目前使用者採用反轉述寫法：${userName} 的行動/對話由 ${userName} 自行在 USER 訊息中描寫，你（AI）不再重複描述 ${userName} 的部分。
因此，你在撰寫本回合的 <horae> 標籤時，必須把「緊接在這則回覆之前的 USER 訊息」中發生的情節也一併納入結算：
  ✦ USER 訊息中出現的物品取得/消耗 → 寫入對應 item:/item-: 行
  ✦ USER 訊息中出現的場景轉移 → 更新 location:
  ✦ USER 訊息中出現的 NPC 互動/好感變化 → 更新 affection:
  ✦ USER 訊息中出現的情節推進 → 在 <horaeevent> 中一併摘要
  ✦ 總之：本則 <horae> 應同時涵蓋「上一則 USER 訊息」和「這則 AI 回覆」兩部分的所有變化
